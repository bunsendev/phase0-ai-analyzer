# 業務担当者確認ガイド

## 目的

実際の業務資料を使い、登録、分析、確認、修正、確定が迷わず行えるかを10〜15分で確認します。AIやOCRの正解率試験ではなく、担当者の操作負担と確認しやすさを評価します。

## 事前準備

- 確認担当者: ____________________
- 実施日: ____________________
- 使用ファイル名: ____________________
- ファイルの正しい大分類: ____________________
- 正しい帳票種類: ____________________
- 確認したい主要項目: ____________________

実データに個人情報・機密情報が含まれる場合、外部サービスへは送信しません。`AI_PROVIDER=mock`で実施してください。

## 操作手順

### 1. 検証ファイルを選ぶ（1分）

1. `data/validation/actual/`から確認対象を1件決めます。
2. TXTは使用せず、XLSX、CSV、PDF、PNG、JPEGから選びます。

____________________________________________________________________

### 2. ファイルを登録する（1分）

1. Streamlitを起動します。
2. 「検証用ファイルを使用する」を開きます。
3. 「検証ファイルを読み取る」を押します。
4. ファイル一覧に対象が表示されることを確認します。

迷った点・コメント:

____________________________________________________________________

### 3. 分析を開始する（1〜2分）

1. 「分析するファイル」でファイルを選びます。
2. 「分析開始」を押します。
3. 状態が「分析済み」または「要確認」になることを確認します。

迷った点・コメント:

____________________________________________________________________

### 4. 要確認を見る（2分）

1. ③「結果確認」に、選んだファイルが表示されることを確認します。
2. 「確認が必要な箇所」のメッセージを読みます。
3. 画像の場合、「画像・手書き帳票のため、OCR結果を確認してください。」が表示されることを確認します。

要確認箇所は見つけやすかったですか:

____________________________________________________________________

### 5. 元データと比較する（2〜3分）

1. 「3. 元データ」まで画面を進めます。
2. 画像は原画像、XLSX/CSVは代表列の表を確認します。
3. 必要な場合だけ「元データの全列を表示」を開きます。
4. AI分類、帳票種類、提供元、対象日、抽出項目を元資料と比較します。

### 6. 間違いを修正する（2分）

1. 間違っている項目だけ変更します。
2. 「修正内容を保存」を押します。
3. 保存件数を確認します。

### 7. 結果を確定する（1分）

1. 内容を再確認します。
2. 「結果を確定」を押します。
3. 確定済み表示を確認します。
