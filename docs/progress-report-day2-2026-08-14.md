## 3. 現在の動作

1. 利用者が`data/upload/`へファイルを配置する
2. 配置しただけでは登録も分析も開始されない
3. 利用者が画面の「一覧更新」を押す
4. 直下の非隠しファイルを走査する
5. 未登録のファイル版だけをSQLiteへ追加する
6. 登録済みファイルを一覧表示する

「一覧更新」はファイル情報の登録だけを行います。ファイル内容解析や分析履歴の作成は行いません。
