## 6. Mock環境の一連フロー

pytestのStreamlit操作テストで以下を確認しました。

```text
ファイル配置
↓
一覧更新
↓
ファイル登録・snapshot保存
↓
分析開始
↓
Mock OCR / Mock AI
↓
詳細表示
↓
修正履歴保存
↓
確定
↓
CONFIRMED
↓
再分析
↓
過去run・確定結果保持
```

確認結果:

| 項目 | 結果 |
|---|---|
| ファイル配置だけでは分析しない | OK |
| 一覧更新でsnapshotを作成する | OK |
| 一覧更新では分析しない | OK |
| 同一ファイルを重複登録しない | OK |
| 分析開始時だけrunを追加する | OK |
| 詳細画面を表示できる | OK |
| 変更項目だけ修正履歴へ追加する | OK |
| AI元結果を変更しない | OK |
| 確定結果を追記する | OK |
| CONFIRMED後に再分析できる | OK |
| 過去run・修正・確定結果を保持する | OK |
